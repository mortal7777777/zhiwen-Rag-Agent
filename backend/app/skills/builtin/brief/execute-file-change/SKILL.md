# Brief 模板：执行类文件改动

执行子代理可以写文件、跑命令，但敏感操作必须交回主代理审批。每轮只放开一个
execute 子任务；brief 必须让"做没做成"可判定。

## 模板

```text
目标：<新建/修改> <唯一产物路径>，实现 <具体功能/修复>。
已知事实：<主代理已确认的接口、约束、历史遗留文件；没有就写"无">。
具体要求：
  1) 只改 <路径>；不得改动其他文件；
  2) 保留 <必须保留的行为/格式>；
  3) 如需命令，只运行 <允许的命令>；涉及安装/删除/提权时不要执行，写明
     "待主代理执行：完整命令与原因"。
验收：<可执行检查，如 `python -m pytest tests/xxx.py -q` 或读取文件核对关键片段>；
  产物必须由本次运行亲手创建/修改，禁止把磁盘上的历史遗留文件当成果。
禁止：不要伪造运行结果；不要跳过验证；不要调用未在工具清单中的工具。
```

## 两个例句

- 空泛：`改一下这个文件，让它能用。`
- 合格：`目标：修改 backend/app/agent/context_pack.py，在 build_context_pack 中保留 3000 字符上限并补充截断标记。已知事实：函数签名已存在，禁止改调用方。具体要求：只改该文件；保留现有段落顺序。验收：运行 python -m pytest tests/test_context_pack.py -q 通过，回报退出码。禁止：不改其他文件、不安装依赖；需要重启后端时写明"待主代理执行"。`

## 主代理检查清单

- [ ] 产物路径唯一且在工作目录内
- [ ] 验收命令可执行、有明确通过标准
- [ ] 明确"只改这个文件"与不得触碰的文件
- [ ] 敏感操作（安装/删除/提权/重启）写成交回主代理
- [ ] 要求回报退出码/关键片段，而不是"已完成"
