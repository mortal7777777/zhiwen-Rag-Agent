# Brief 模板：多书 / 多主题研究

用途：把"帮我研究一下 X"改写成子代理能独立执行的**自包含任务书**。
子代理看不到主对话，任务书必须自带目标、产出、验收与禁止事项。

## 模板

```text
目标：对比《书名A》《书名B》在「具体议题」上的观点差异，回答「具体问题」。
已知事实：<主代理已确认的结论/页码/链接；没有就写"无，需要你检索确认">。
产出：<文件路径或结构化文本格式>，至少包含：
  1) 每本书的核心观点（含 [n] 来源编号/页码）；
  2) 逐维度对照表（维度 1..3）；
  3) 分歧点与可能原因；
  4) 未找到/不确定项（明确列出）。
验收：每个结论都能追溯到来源；对比表维度一致；不编造书名、页码或引文。
禁止：不要修改任何文件；不要执行命令；不要回答任务之外的问题。
```

## 两个例句

- 空泛（不要这样写）：`研究一下这两本书的区别。`
- 合格：`目标：对比《RAG 实践》与《LangChain 指南》在"检索评估指标"上的差异，回答"哪本书更适合入门 RAGAS"。已知事实：两书均已在知识库，未核实章节。产出：对照表 + 分歧点，写入 notes/rag-eval-compare.md。验收：每条给 [n] 与页码；无来源的结论标"未找到"。禁止：不改其他文件、不执行命令。`

## 主代理检查清单

- [ ] 目标里点名了具体书/文档与具体议题
- [ ] 产出物有路径或明确格式
- [ ] 验收标准可判定（来源、维度、禁编造）
- [ ] 禁止事项覆盖写文件/执行命令（research/explore 模式）
- [ ] 已知事实与未确认项分开写
